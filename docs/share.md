## English

**AI Website Deploy Skill — deploy an existing website with your AI coding agent**

A reusable agent skill for Netlify frontend deployment, an optional Render backend,
and real frontend-to-API verification. Start with an existing website, keep private
source private, and add storage only when user data needs to persist. Includes free-tier
limits, private-repository credential checks, and mainland China/overseas access checks.

Install: `npx skills add chrisoops500/ai-website-deploy-skill`

Project: https://github.com/chrisoops500/ai-website-deploy-skill
